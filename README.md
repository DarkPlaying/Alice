# ALICE: Borderland Survival Platform

![Alice Banner](/about-image.jpg)

**ALICE** is a high-stakes, immersive survival game platform inspired by the "Alice in Borderland" universe. Built with cutting-edge web technologies, it provides a seamless, real-time experience where players must compete in various challenges to survive.

---

## 🃏 The 4 Suits of Survival

Every game in ALICE is categorized by a card suit, defining the nature of the challenge:

-   **♠ Spades (Physical)**: Tests of strength, endurance, and physical prowess. Harder and deadlier with every level.
-   **♦ Diamonds (Intellectual)**: Games of logic, knowledge, and calculation. There are no second chances for a wrong answer.
-   **♣ Clubs (Balanced)**: Focuses on teamwork, strategy, and cooperation. But beware—allies can quickly become traitors.
-   **♥ Hearts (Psychological)**: The cruelest of all. Tests of betrayal, empathy, and mental manipulation. Decide fast—or die.

---

## 🚀 Tech Stack

-   **Frontend**: React 18, TypeScript, Vite
-   **Styling**: Tailwind CSS, Framer Motion (for cinematic animations)
-   **Backend/Auth**: Firebase (Authentication & User Profiles)
-   **Real-time Logic**: Supabase (Realtime Channels, PostgreSQL)
-   **Deployment**: Vercel

---

## 🛠️ Key Features

-   **Cinematic UI**: A dark, premium aesthetic with glitch effects and parallax scrolling.
-   **Real-time Multiplayer**: Powered by Supabase Realtime for instant synchronization between players.
-   **Survival Protocol**: Automated game status guards and player tracking.
-   **Admin Dashboard**: Comprehensive control panel for game masters to monitor and manage active sessions.
-   **Leaderboard**: Persistent tracking of survivors and their achievements.

## 📥 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-repo/alice-borderland.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Set up environment variables**:
    Create a `.env` file with your Firebase and Supabase credentials.
4.  **Run the development server**:
    ```bash
    npm run dev
    ```
